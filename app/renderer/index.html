    帮助 / 救援

    基本用法

    1. 点击键盘上的键, 在右侧属性面板选功能卡片: 默认 / 键盘功能(含组合键捕捉) / 禁用; 灰色卡片为本键盘固件不支持的功能。
    2. 每次点"应用"只是改软件里的草稿, 不会碰键盘。
    3. 确认底部"待下发变更"无误后, 点"写入到键盘"才会真正写入。下发期间请勿拔线或按键。
    4. 改错了随时选中该键选"默认功能"再下发即可恢复; 或直接点顶栏"一键还原"清除全部改动并写回默认。

    安全机制

    写入前软件会先探测设备心跳; 会话中任何一步设备应答异常都会立即熔断中止, 不再发送任何数据, 状态栏红字提示。看到熔断提示时: 拔插 USB 后重试即可, 键盘不受影响。

    故障自查

    • 检测不到设备: 先关闭老配置软件(GM108 Keyboard.exe), 它独占设备; 再拔插 USB。
    • 徽章显示 BOOT (黄色): 键盘处于刷固件模式(设备 ID 7040), 见下方救援流程收尾。
    • 下发中止: 红字会写明在哪一步熔断, 拔插 USB 重试; 反复失败请不要再强行写入。

    键盘救砖 (K3-BOOT 救援)

    仅在键盘完全无反应(所有键+灯全灭)时才需要。正常使用时软件熔断机制保证不会走到这一步。

    1. 准备好官方刷写工具: firmware\GM108_Keyboard_V1.16_0304_firmware.exe(本工具项目目录内, 网上下载不到, 务必备份)。
    2. 断开键盘 USB, 打开键盘后壳。
    3. 在主板上找到 K3-BOOT 触点(空格键附近, 两个焊盘)。
    4. 用导体按住(短接)K3-BOOT 不放 → 插上 USB 上电 → 松开。
    5. 此时键盘以刷固件模式枚举(设备管理器 VID_0C45&PID_7040), 运行官方刷写工具, 按工具提示刷入固件。
    6. 刷完拔插 USB, 键盘恢复正常, 本工具重新识别。

    严禁: 在 BOOT 模式(7040)下用本工具或任何改键软件发送配置报文; 严禁用第三方烧录器直接刷 .bin 备份(官方刷写含传输加密, 第三方刷入会变砖)。救援只许用官方 exe + K3-BOOT。
