      基本用法

      1. 在"按键映射"里点击键盘上的键, 在右侧面板选择功能: 默认 / 键盘功能(含组合键) / 鼠标 / 宏 / 连击 / 快捷键 (Windows、macOS 系统快捷键) / 多媒体 / 禁用。
      2. 每次点"应用到草稿"只是改软件里的草稿, 不会碰键盘。
      3. 确认底部"待下发变更"无误后, 点"写入到键盘"才会真正写入。下发期间请勿拔线或按键。
      4. 宏在"宏库"页录制和编辑, 保存后回到"按键映射"把它绑到某个键上。
      5. 改错了随时选中该键选"默认"再写入即可恢复; 或点顶栏"一键还原"清除全部改动并写回默认。

      安全机制

      写入前软件会先探测设备心跳; 会话中任何一步设备应答异常都会立即熔断中止, 不再发送任何数据, 状态栏红字提示。这能大幅降低写坏键盘的风险, 但不能百分之百保证。看到熔断提示时: 拔插 USB, 确认键盘能正常打字后再重试; 中途中止的下发会把"键盘当前状态"标记为未知, 下次自动全量写入。

      故障自查

      • 检测不到设备: 先关闭老配置软件(GM108 Keyboard.exe), 它独占设备; 再拔插 USB。
      • 徽章显示 BOOT (黄色): 键盘处于刷固件模式(设备 ID 7040), 见下方救援流程收尾。
      • 下发中止: 红字会写明在哪一步熔断, 拔插 USB 重试; 反复失败请不要再强行写入。
      • 用老软件改过键盘 / 换了电脑: 本工具记录的"键盘当前状态"已不准, 先点下面的按钮, 下次写入会全量下发。

      键盘救砖 (K3-BOOT 救援)

      仅在键盘完全无反应(所有键+灯全灭)时才需要。熔断机制会尽量避免走到这一步。

      1. 准备好官方刷写工具: firmware\GM108_Keyboard_V1.16_0304_firmware.exe(本工具项目目录内, 网上下载不到, 务必另行备份到网盘)。
      2. 断开键盘 USB, 打开键盘后壳。
      3. 在主板上找到 K3-BOOT 触点(空格键附近, 两个焊盘)。
      4. 用导体按住(短接)K3-BOOT 不放 → 插上 USB 上电 → 松开。
      5. 此时键盘以刷固件模式枚举(设备管理器 VID_0C45&PID_7040), 运行官方刷写工具, 按工具提示刷入固件。
      6. 刷完拔插 USB, 键盘恢复正常, 本工具重新识别。

      严禁: 在 BOOT 模式(7040)下用本工具或任何改键软件发送配置报文; 严禁用第三方烧录器直接刷 .bin 备份(官方刷写含传输加密, 第三方刷入会变砖)。救援只许用官方 exe + K3-BOOT。
